## 🎯 About This Repository
This repository showcases three production-ready Python automation projects that solve common IT operations challenges. Each project demonstrates different aspects of Python programming, from data analysis to text processing.

## 📁 Projects

### 1. [IT Ticket Analyzer](./Project1_IT_Ticket_Analyzer/)
Automated ticket analysis tool using Pandas for data processing and statistical reporting.

**Key Features:**
- Analyzes 100+ support tickets from CSV files
- Generates reports on resolution times and category trends
- Reduces manual reporting time by 80%

**Technologies:** Python, Pandas, CSV, Data Analysis

---

### 2. [User Provisioning Automation](./Project2_User_Provisioning/)
Bulk user account creation script with email validation and error handling.

**Key Features:**
- Email validation using regex
- Standardized username generation
- Separate output files for success/error records
- Audit logging with timestamps

**Technologies:** Python, Regex, CSV, File I/O, Logging

---

### 3. [System Health Monitor - Log Parser](./Project3_Log_Parser/)
Advanced log file parser for system health monitoring and error analysis.

**Key Features:**
- Regex-based log parsing
- Error categorization by severity (INFO, WARNING, ERROR, CRITICAL)
- Frequency analysis of recurring errors
- Temporal analysis (errors by hour)
- Critical event timeline

**Technologies:** Python, Regex, Text Processing, Data Analysis
